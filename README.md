## 📁 Портфолио

- 🐂 [**BullMC Client Launcher**](https://github.com/idnyakrytoi-afk/bulauncher) — десктопный Minecraft-лаунчер для BullMC.
- 📦 **Community Builds** — каталог готовых сборок от игроков с установкой в один клик.
- 🧩 **Mod Browser** — поиск и установка модов из Modrinth / CurseForge.
- 🛠️ **Crash Reporter** — анализ логов и подсказки по ошибкам запуска.
- 🎨 **Theme System** — темы, анимации, splash screen и кастомные UI-компоненты.

## 🔗 Другие проекты

Я развиваю BullMC Client как основу для своего лаунчер-движка:

- 🧰 релизная сборка в `.jar`, `.exe`, `.msi` и portable `.zip`;
